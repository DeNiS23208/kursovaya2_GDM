# Приложение для анализа вакансий  

## Описание  
Этот проект представляет собой приложение для поиска, сохранения и анализа вакансий. Данные о вакансиях загружаются с платформы HeadHunter через API и могут быть сохранены в файл `vacancies.json` для дальнейшего использования.  

## Функциональность  
- Получение вакансий с HeadHunter API  
- Сохранение вакансий в JSON-файл  
- Фильтрация и сортировка вакансий по ключевым параметрам  
- Тестирование основных функций с помощью `pytest`  

## Установка и запуск  
1. Клонируйте репозиторий:  
   ```sh
   git clone <URL-репозитория>
   cd kursovaya2_GDM
   ```
2. Установите зависимости с помощью `Poetry`:  
   ```sh
   poetry install
   ```
3. Запустите скрипт:  
   ```sh
   poetry run python main.py
   ```
4. Запустите тесты:  
   ```sh
   poetry run pytest
   ```
